# Проект UI-автотестов с Allure-отчётами

Этот проект содержит автотесты для двух веб-приложений:  
- **Калькулятор с задержкой** (сайт `bonigarcia.dev`)  
- **Интернет-магазин** (`saucedemo.com`)

Тесты написаны на Python с использованием `pytest`, `Selenium` и паттерна Page Object.  
Для генерации красивых отчётов о выполнении тестов используется **Allure**.

---

## 📖 Как я оформляю код

Я стараюсь писать код так, чтобы его было легко читать и поддерживать:

- **Имена переменных и функций** – осмысленные, на русском или английском, но понятные.
- **Документация** – для каждого класса и метода я добавляю пояснение (`docstring`), указываю типы параметров и что возвращает метод.
- **Аннотации типов** – например, `-> str` или `: int` – чтобы сразу было ясно, какие данные передаются и получаются.
- **PEP8** – соблюдаю отступы, длину строк (до 79 символов) и другие правила форматирования.

Для Allure я использую декораторы:
- `@allure.title` – короткое название теста,
- `@allure.description` – подробное описание,
- `@allure.feature` – к какой функции относится тест,
- `@allure.severity` – критичность (blocker, critical, normal, minor, trivial).

Шаги теста я размечаю через `with allure.step("...")`, чтобы в отчёте было видно, что именно происходит.

## 🛠️ Как запустить тесты и получить отчёт Allure

1. Установка зависимостей

Если у вас ещё нет нужных библиотек, выполните:

```bash
pip install -r requirements.txt

Или, если файла requirements.txt нет, установите вручную:

bash
pip install pytest selenium webdriver-manager allure-pytest
2. Запуск тестов с сохранением результатов
Из корня проекта выполните команду:

bash
pytest lesson_10/ --alluredir=./allure-results
Все тесты из папки lesson_10 запустятся, а результаты сохранятся в папку allure-results.

3. Просмотр отчёта
Чтобы открыть сгенерированный отчёт, введите:

bash
allure serve ./allure-results
Если команда allure не распознаётся (такое бывает в Windows), используйте полный путь (после установки Allure через Scoop):

bash
C:\Users\%USERNAME%\scoop\apps\allure\current\bin\allure.bat serve ./allure-results
После этого откроется браузер с красивым отчётом, где видны все тесты, их шаги, статусы, вложения и графики.
