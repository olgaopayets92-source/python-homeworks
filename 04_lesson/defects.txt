Дефект №1: Метод contains возвращает True для пустого символа

- Описание: при поиске пустой строки ("") метод contains возвращает True, хотя документация предполагает поиск символа, и пустой символ не должен считаться найденным.
- Шаги воспроизведения:
  1. Вызвать contains("abc", "")
- Ожидаемый результат: False
- Фактический результат: True
- Пример: contains("abc", "") -> True (ожидалось False)
- Серьёзность: низкая (маловероятный сценарий, но несоответствие логике)
- Статус: открыт

Дефект №2: Метод capitalize изменяет регистр всех символов, а не только первого

- Описание: capitalize приводит все символы, кроме первого, к нижнему регистру, что не соответствует описанию «делает первую букву заглавной».
- Пример: capitalize("SkyPro") -> "Skypro", ожидалось "SkyPro".
- Серьёзность: низкая (стандартное поведение Python, но несоответствие документации).
- Примечание: это поведение соответствует встроенному методу str.capitalize(), но не соответствует описанию в документации.
- Рекомендация: либо изменить документацию, либо реализовать кастомный метод, который меняет только первую букву.

Дефект №3: Метод contains не обрабатывает None

- Описание: при передаче None в качестве строки или символа метод выбрасывает исключение AttributeError.
- Ожидаемое поведение: возвращать False или обрабатывать как пустую строку.
- Пример: contains(None, "a") -> исключение.
- Серьёзность: средняя (могут быть случаи, когда приходит None).

Дефект №4: Метод delete_symbol не обрабатывает None

- Аналогично, при передаче None выбрасывает исключение.

- Подтверждён тестами: test_contains_negative с параметром (None, "a", False) и test_delete_symbol_negative с (None, "a", None) падают, что указывает на отсутствие обработки None.
